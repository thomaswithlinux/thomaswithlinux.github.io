# Utilisation du site

Guide du visiteur : comment parcourir le portfolio, y compris les fonctions cachées.

## Naviguer

| Moyen | Effet |
| --- | --- |
| Menu latéral | Accès direct aux sections ; la section en cours est surlignée |
| Barre de progression | Fine ligne en haut de l'écran : avancement de la lecture |
| `Ctrl/⌘ + K` | Ouvre la **palette de commandes** |
| Bouton ☰ (mobile) | Ouvre le menu en tiroir |
| « Haut de page ↑ » | Dans le pied de page |

## Palette de commandes

Ouvrir avec `Ctrl + K` (`⌘ + K` sur Mac) ou en cliquant sur la zone « Rechercher… ».

| Touche | Action |
| --- | --- |
| Texte | Filtre les entrées (sections, projets, liens) |
| `↑` `↓` | Change la sélection |
| `Entrée` | Valide |
| `Échap` | Ferme |

Entrées disponibles : chaque section, chaque projet, « Copier l'adresse e-mail », « Ouvrir GitHub », « Ouvrir LinkedIn ».

## Terminal interactif

Dans l'accueil, une démonstration se joue seule, puis le terminal devient utilisable : cliquer dans le champ et taper une commande. `↑`/`↓` rappellent l'historique.

| Commande | Résultat |
| --- | --- |
| `help` | Liste des commandes |
| `whoami` | Nom, poste, localisation, statut |
| `skills` | Compétences par domaine |
| `projects` | Liste des projets |
| `experience` | Parcours professionnel |
| `contact` | E-mail et liens |
| `goto <section>` | Défile jusqu'à la section (`about`, `skills`, `projects`, `archive`, `experience`, `education`, `contact`) |
| `ls` | Liste des sections |
| `clear` | Vide le terminal |
| `sudo` | À vous de voir 😉 |

## Projets et dépôts

- Les **boutons de catégorie** au-dessus des projets filtrent la grille ; « Tous » réaffiche tout.
- Une carte avec une flèche ↗ ouvre le dépôt GitHub correspondant dans un nouvel onglet.
- Le champ de l'archive filtre par nom, type ou technologie ; le compteur indique le nombre d'entrées affichées.

## Contacter

- **Copier** : le bouton de la carte « E-mail » copie l'adresse dans le presse-papiers.
- **Formulaire** : « Envoyer via ma messagerie » ouvre votre application de messagerie avec le message prérempli. Rien n'est envoyé au site.

## Préférences d'affichage

- Le site respecte « **réduire les animations** » (système d'exploitation) : écran de démarrage ignoré, fond fixe, texte sans défilement.
- Entièrement utilisable **au clavier** (focus visible, lien d'évitement « Aller au contenu »).
- Adapté du téléphone (375 px) au grand écran.
- L'écran de démarrage ne se rejoue pas pendant la même session ; fermer l'onglet pour le revoir.
